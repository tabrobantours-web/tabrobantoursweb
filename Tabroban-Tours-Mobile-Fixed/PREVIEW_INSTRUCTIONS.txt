TABROBAN TOURS WEBSITE — HOW TO PREVIEW

IMPORTANT
The previous V5 package was missing CSS/JavaScript/logo files.
This V6 package includes them.

1. Extract the ENTIRE ZIP first.
2. Keep index.html and the assets folder together.
3. Do not open index.html from inside the ZIP archive.
4. Open index.html in Chrome, Edge, or Safari.

Recommended local preview:
  python3 -m http.server 8080

Then visit:
  http://localhost:8080

An internet connection is still required for the current prototype's
remote Sri Lankan photography, Google Fonts and GSAP CDN.
